# 证据核验基线 — 具身智能与物理 AI：离线 agent + Real2Sim + 真机验证

> 项目：`embodied-physical-ai` ｜ 核验日：2026-11-19 ｜ 版本：evidence-baseline v1
> 来源：2026-11-19 六方向并行检索（4 路子代理 + 主会话独立验号），原始综述由用户提供。
> 纪律：arXiv 编号必须 abs 页「号—题—作者」一致才算核实；官方通稿数字只作**事件**证据，不作**性能**证据；
> 自我报告（self-report）与独立测量分开记；同一断言两次核验不一致时列出冲突，不开第三条路。

## 核验方法

1. 每条断言反查到**一手载体**：arXiv abs 页 / 期刊 DOI 页 / 官方博客 / 校方或机构通报。
2. 判定四档：`已核实`（一手载体与断言一致）、`已核实·口径受限`（事实成立但数字口径需改写）、`事件已核实·无一手论文`（发布真实、性能数字仅官方口径）、`未核实`（载体不可达或找不到出处）。
3. 否定证据（"某机构并未做某事"）同样要求一手载体，单独立一条。
4. 冲突项单列「冲突与存疑」，不静默取一个。

## 未核实 / 冲突与存疑

- **Claude Fable 5.2 在 RoboDojo 得 64.9%**：无 Anthropic 一手源，判断为误传，不进稿。
- **Gemini Robotics 2.5（2026-11-10）细节**：抓取时超时，未全核，暂只记「存在发布」。
- **GR00T 2 的零样本 50 任务清单与评测协议**：官方未公开，40% 与 95% 两个数字的评测条件不可复算。

## 本项目的证据缺口（下一步取证目标）

1. **「离线生成 + 真机验证」的成功率方差无人报告**：ACE-CaP-0 的 92.1% 与 RoboBuilder 的 66% 复现率指向同一问题——跨任务/跨场景的稳定性，而非均值。
2. **Real2Sim 保真度缺量具**：SimFoundry 给 Pearson 0.92，但「仿真像不像」与「策略在真机成不成」之间无因果链证据。
3. **无模型在环的成本被低估**：GaP 的真机阶段无模型在环，但写程序的 agent 侧成本（token/墙钟/人工复核）无人计入（注：「无模型在环」为作者叙事框架，本轮全文未核到 GaP 逐字原句，此处作为 H1 假设保留，不作既成事实）。
4. **GR00T 2 复现窗口未开**：权重未放出，所有第三方结论都是「官方自测」的转述，需等 12 月开放后重测。

## 引用纪律（写稿时强制）

- 表格里 `事件已核实·无一手论文` 的条目，正文只能写「发布/宣布」，不能写「证明/达到」。
- `已核实·口径受限` 的条目，数字必须带口径限定语（自我报告 / 论文自选任务 / 厂商通稿）。
- `未核实` 的条目在正式稿中删除，或标 `[待核]` 并在提交前复查。
