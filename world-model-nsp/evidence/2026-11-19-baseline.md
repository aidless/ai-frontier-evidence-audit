# 证据核验基线 — 世界模型与 Next-State Prediction (NSP)

> 项目：`world-model-nsp` ｜ 核验日：2026-11-19 ｜ 版本：evidence-baseline v1
> 来源：2026-11-19 六方向并行检索（4 路子代理 + 主会话独立验号），原始综述由用户提供。
> 纪律：arXiv 编号必须 abs 页「号—题—作者」一致才算核实；官方通稿数字只作**事件**证据，不作**性能**证据；
> 自我报告（self-report）与独立测量分开记；同一断言两次核验不一致时列出冲突，不开第三条路。

## 核验方法

1. 每条断言反查到**一手载体**：arXiv abs 页 / 期刊 DOI 页 / 官方博客 / 校方或机构通报。
2. 判定四档：`已核实`（一手载体与断言一致）、`已核实·口径受限`（事实成立但数字口径需改写）、`事件已核实·无一手论文`（发布真实、性能数字仅官方口径）、`未核实`（载体不可达或找不到出处）。
3. 否定证据（"某机构并未做某事"）同样要求一手载体，单独立一条。
4. 冲突项单列「冲突与存疑」，不静默取一个。

## 未核实 / 冲突与存疑

- **LeCun 2022《A Path Towards Autonomous Machine Intelligence》**：OpenReview 页面返回 403，立场文原文未取到。引用其观点需另找可访问副本。
- **「Jakarta 与 NSP 关联」**：无任何权威出处，判断为误传，不进稿。
- **Genie 4 的 FPS / 分辨率 / 一致性时长**：官方未披露，现有二手数字不可引用。

## 本项目的证据缺口（下一步取证目标）

1. **三臂对照缺失**：固定 backbone 下 next-token / next-frame / action-conditioned NSP 的长时程误差累积曲线（horizon 10/100/1000）无人系统报告——H1 的直接判据。
2. **NSP 增益来源未解耦**：现有论文同时改表征、改监督、改数据，无法分离「动作条件监督」的净贡献——H1/H2 的共同前提。
3. **可交互性无统一 benchmark**：token 带宽下界只有厂商推导，缺少跨模型的同一底物测量——H3 的判据。
4. **感知-效用脱节未量化到单模型级**：WorldArena 给的是榜面差距，缺「同一模型感知分高、效用分低」的逐模型证据。

## 引用纪律（写稿时强制）

- 表格里 `事件已核实·无一手论文` 的条目，正文只能写「发布/宣布」，不能写「证明/达到」。
- `已核实·口径受限` 的条目，数字必须带口径限定语（自我报告 / 论文自选任务 / 厂商通稿）。
- `未核实` 的条目在正式稿中删除，或标 `[待核]` 并在提交前复查。
