# AI for Science：自主发现系统的证据结构

> 项目 id：`ai4science` ｜ 领域：`ai/ai4science` ｜ 建立：2026-11-19 ｜ 状态：scoping
> 发布事件、论文、可复现三者之间的落差

## 核心研究问题

自主科学发现系统（AI scientist / self-driving lab）的产出，在多大比例上可被独立复现与同行评审接受？其瓶颈是假设生成、实验自动化还是验证？

## 假设（待检验，非结论）

- **H1** 当前 AI4S 高影响力案例中，「有论文且可复现」的比例显著低于「有新闻发布」的比例（证据结构失衡）。
- **H2** 闭环自主实验室（如 MIT CRESt）的增益主要来自实验吞吐与贝叶斯优化，而非 LLM 的科学洞察。
- **H3** 「科学家效率提升 1.9×」是自我报告口径；真实加速需随机对照测量。

## 已核验证据基线

| 结论 / 事实 | 证据 | 等级 |
|---|---|---|
| MIT CRESt：3 个月 900+ 配方、3500 次测试、八元化学空间、成本专用性能 9.3× | Nature 647:390–396 (2025-09-23), doi:10.1038/s41586-025-09640-5 | 同行评审·已核实 |
| GeneScientist：基于种业大模型「丰登」；30 万条推理链；无 arXiv/期刊论文 | 中国农大官方 (2025-07-30) | 官方口径·事件已核实/数字存疑 |
| NanoTitan Ultra：成本降超 90%；无论文、无独立 benchmark | 重庆市政府/科技日报 (2026-07-16) | 媒体通稿·事件已核实/数字存疑 |
| OpenAI 1.9×：1,819 名科学家、580,186 条消息、251 人调查；8 类活动自报均值，非实验 | Science at the Frontier (2026-11-16) | 官方报告·已核实 |
| A-Lab 自主无机材料合成（有公开质量争议，作为对照组） | Nature (2023-11-29), doi:10.1038/s41586-023-06734-w | 同行评审·有争议 |

> 完整核验记录与「未核实/存疑」清单见 [`evidence/2026-11-19-baseline.md`](evidence/2026-11-19-baseline.md)。
> 纪律：arXiv 编号必须 abs 页「号-题-作者」一致才算核实；官方通稿数字只作事件证据，不作性能证据。

## 研究缺口（本项目的切入点）

- GeneScientist 与 NanoTitan Ultra 均为「发布事件真实、论文缺位」，数字只能作官方口径。
- 「企业与高校共建自主实验室」未核实到专门项目名；最近似对应为 MIT CRESt（有工业合作）。
- 1.9× 为自选样本 + 自我报告，外部效度有限。

## 可执行的第一步

1. 建立 AI4S 案例证据台账，每案三列：论文 / 独立复现 / 新闻，并打 A–D 证据等级。
2. 对 1.9× 设计随机对照测量方案（同任务、同人、有无 AI 的配对计时）。
3. 以 CRESt 为模板，拆分增益来源：吞吐 vs 优化 vs LLM 假设质量。
