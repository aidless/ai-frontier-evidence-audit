# 证据核验基线 — AI for Science：自主发现系统的证据结构

> 项目：`ai4science` ｜ 核验日：2026-11-19 ｜ 版本：evidence-baseline v1
> 来源：2026-11-19 六方向并行检索（4 路子代理 + 主会话独立验号），原始综述由用户提供。
> 纪律：arXiv 编号必须 abs 页「号—题—作者」一致才算核实；官方通稿数字只作**事件**证据，不作**性能**证据；
> 自我报告（self-report）与独立测量分开记；同一断言两次核验不一致时列出冲突，不开第三条路。

## 核验方法

1. 每条断言反查到**一手载体**：arXiv abs 页 / 期刊 DOI 页 / 官方博客 / 校方或机构通报。
2. 判定四档：`已核实`（一手载体与断言一致）、`已核实·口径受限`（事实成立但数字口径需改写）、`事件已核实·无一手论文`（发布真实、性能数字仅官方口径）、`未核实`（载体不可达或找不到出处）。
3. 否定证据（"某机构并未做某事"）同样要求一手载体，单独立一条。
4. 冲突项单列「冲突与存疑」，不静默取一个。

## 未核实 / 冲突与存疑

- **GeneScientist 与 NanoTitan Ultra 的科学结果**：两者都只有发布通报，缺 arXiv/期刊与可复算协议。写稿必须停在「宣布」层。
- **FutureHouse Kosmos（2025-11）**：仅厂商口径，未核。
- **「企业与高校共建 AI 驱动自主实验室用于电化学催化剂研发」**：除 CRESt 外未定位到第二个可核实主体，暂按单一案例处理。

## 本项目的证据缺口（下一步取证目标）

1. **证据结构断层**：本项目最该研究的不是「AI 能不能做科学」，而是「为什么同领域的成果证据等级差三个数量级」——CRESt 有 Nature 与 3500 次实测，GeneScientist 只有通报。
2. **自我报告效率缺对照**：1.9× 无能对照组、无任务日志，与 CRESt 的 9.3× 不可同表比较。需要的是「同一课题组、同一任务、有/无工具」的配对测量。
3. **自主性的判据缺定义**：从「LLM 提假设」到「机器人执行」到「闭环修正」，各系统的自主层级无人统一标注，导致排名失真。
4. **失败案例系统性缺失**：现有报告只报发现的基因/材料，不报被证伪的假设比例——这是判断自主科学系统可靠性的关键分母。

## 引用纪律（写稿时强制）

- 表格里 `事件已核实·无一手论文` 的条目，正文只能写「发布/宣布」，不能写「证明/达到」。
- `已核实·口径受限` 的条目，数字必须带口径限定语（自我报告 / 论文自选任务 / 厂商通稿）。
- `未核实` 的条目在正式稿中删除，或标 `[待核]` 并在提交前复查。
