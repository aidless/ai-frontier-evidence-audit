# E2 「1.9× 自我报告效率」内部一致性与可审计性诊断

> 项目：`ai4science` ｜ 卡：E2-tool-selfreport-audit ｜ 日期：2026-11-21
> 性质：**公开数字的算术自检 + 可识别性诊断，不是配对实测（底物：人类受试者 + 任务日志，不可得）**

## 结论先行

OpenAI 报告（2026-11-16）称 8 类科研活动自我报告时间比均值为 1.9×，公开了其中 5 个分项：代码 2.83 / 阅读 2.21 / 分析 2.05 / 构思 1.86 / 写作 1.76（`ai4science/evidence/2026-11-19-baseline.md:25`）。对这 5 个公开数字做算术自检：

- 5 项算术均值 = **2.142**，中位数 = 2.05，几何均值 = 2.112——**没有一个等于 1.9**。
- 若 1.9 是 8 项算术均值，未公开的 3 项须平均 **1.497**，低于所有已公开分项（最低 1.76）。
- 更强：即便未公开 3 项都取公开最小值 1.76，8 项均值下界也是 **1.9988 > 1.9**；可行区间 [1.999, 2.400] 根本不含 1.9。即 1.9 与公开分项在「同口径平均」下**彻底不相容**。

**判决**：1.9× 无法从公开数字复现——要么用了未公开的权重/不同分项集，要么 headline 与分项口径不一致；两种情况都使 1.9× 成为一个**不可从公开材料审计的数字**。更进一步，原卡判据「1.9× 与配对实测的偏离方向与幅度」在数学上**不可识别**：没有配对、没有方差、没有对照组，自我报告偏差可正可负、幅度无界，只能给恒等变换（时间比 r → 节省 1−1/r），不能给方向或点估计。

## 装置与口径

- 输入仅为公开数字，每个带出处；不引入任何配对实测值、不造对照组。
- 四个预注册判据（脚本 `--selftest` 注入反证验证门能红）：
  1. headline ≠ 公开 5 项均值；
  2. 隐含未公开 3 项均值 < 公开最小值；
  3. headline 落在可行均值区间之外；
  4. 常用集中趋势（mean/median/geomean）无一等于 headline。
- selftest 另验：把 headline 替换成公开均值会翻转判据 1；注入高 headline 会翻转隐含未公开项的方向。

## 结果表

| 量 | 值 |
|---|---|
| 公开 5 项 | 2.83 / 2.21 / 2.05 / 1.86 / 1.76 |
| 5 项算术均值 / 中位数 / 几何均值 | 2.142 / 2.05 / 2.112 |
| 隐含未公开 3 项均值（若为 8 项均值） | 1.4967（< 公开最低 1.76） |
| 可行均值区间（未公开项∈[1.76,2.83]） | [1.9988, 2.400]（不含 1.9） |
| 四项一致性判据 | 全 TRUE（1.9 与公开分项不相容） |
| 时间节省恒等变换 | 1.9×→47.4%；公开均值 2.142×→53.3% |

## 诚实边界

1. 这是算术一致性诊断，**不声称** 1.9× 是错的——只说它无法从公开分项复现、聚合口径未公开。原始报告可能用了加权或不同分项集，本诊断无法判定是哪一种。
2. `1−1/r` 是恒等变换，不是因果效应；r 是自我报告则节省比例同样是自我报告口径，不能当真实时间节省。
3. 偏离的「方向/幅度不可识别」是数据结构的性质（无配对无方差），不是本次诊断的发现局限——补它只能靠人类受试者配对实验，底物当前不可得。
4. 与 E1 的 33 条分级一致：`openai2026science` 在该分级里是 `ANNOUNCEMENT_ONLY`（composite 0.2507，A3/B3/C3），本诊断从另一角度独立支持「不可作性能证据」。
